From products to reports, Open ERP has you covered with a clean, intuitive interface.

Products & Inventory

Full product management with stock tracking, barcodes, categories, and multi-warehouse inventory with Kardex movement records.

HR & Payroll

Complete human resources module with employee management, attendance tracking, payroll processing, loans, bonuses, and leave management.

Sales & POS

Create invoices, track payments, and manage your point of sale with quick-sale interface, product search, and electronic DTE document generation.

Accounting & Reports

Hierarchical chart of accounts, company configuration with El Salvador DTE compliance, and real-time dashboard analytics.

Installation

Get Started with Open ERP

Choose your installation method

Docker Recommended

Quick & consistent setup

Requirements

  • Docker
  • Docker Compose
  • Git
git clone https://github.com/ErickGBR/open-erp-mvp.git
cd open-erp-mvp
docker compose up --build -d

Ubuntu Server Installer

Linux server setup

Requirements

  • Ubuntu 22.04+
  • sudo access
  • curl
  • openssl
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/ErickGBR/open-erp-mvp/main/install.sh)"
