# Open ERP

Open-source Enterprise Resource Planning system.

## Stack
- **Backend:** NestJS + TypeScript + PostgreSQL
- **Frontend:** Next.js + TypeScript + Tailwind CSS

## Quick Start
```bash
# Backend
cd backend
npm install
cp .env.example .env
npm run start:dev

# Frontend
cd frontend
npm install
cp .env.example .env
npm run dev
```
